# 總體版 demo（約 4 分鐘）

給誰：總評審、決賽台下、第一次聽到這個專案的人。一句話講清楚我們是什麼，再用三個畫面證明。
ETHGlobal 的評審 demo 一般抓 4 分鐘（以現場公告為準）；超時就砍第 4 幕，不要砍第 3 幕。

> 一句話：**《無界之地》是一個沒有地圖的世界。你走到哪裡，AI 才把那裡寫出來；朋友的世界會和你的連成一片大陸。**

準備工作見 [setup.md](setup.md)。畫面上的按鈕名稱以目前版本為準；第二段（標題改成「繼續・世界・創造世界・設定」）上線後，照 [README](README.md#第二段上線後要改的地方) 換掉入口名稱。

## 逐幕腳本

### 開場（20 秒）
- **說**：「大部分遊戲的世界是先做好、再讓你走。我們反過來：一開始什麼都沒有，你走到哪，AI 才把那裡寫出來。寫過的地方就是歷史，朋友來了也看得到。」
- **做**：不用點，讓標題背後的大地動著。

### 第 1 幕：幾個字變成一個世界（60 秒）
- **做**：標題「創作遊戲」→「開始新的遊戲」→ 世界名稱填「鐘錶城」、一句話填「沙漠裡的鐘錶城」→「撰寫世界」。
  目前版本**一定要填名稱**，空著「撰寫世界」按不下去（排練實測）；第二段上線後才會變成只要幾個字。
- **螢幕**：七張世界卡（起源、基調、命名、語氣……第七張是這個世界自己的美術風格）一張張長出來；「繼續寫故事」→ 章節也一張張出現。串流預覽在 1440×868 的視窗裡位於捲動區下方，要先往下捲才看得到字在長。
- **說**：「我只給了幾個字。AI 先寫世界的設定卡，再寫故事的章節，都是邊寫邊顯示，玩家不用盯著轉圈圈。每一張卡都可以自己改、單獨重寫。」
- **做**：「前往建立」→「建立並開始玩」→ 進入大地。
- **說**：「建立的時候，AI 用我們自己的小語言寫出起點場景；程式先解析、檢查，有錯就只叫它修壞掉的那幾句，最多兩次。過不了就顯示錯誤，絕不塞一個假的場景。」
- **備援**：模型慢（超過 20 秒還沒出卡）時，直接說「這一步大約要半分鐘，我先開剛才建好的」→ 回標題 → 繼續，用事先建好的世界接第 2 幕。

排練量到的數字（[milestone-demo-flow](../e2e/milestone-demo-flow/result.md)，`gpt-5.4-mini`）：七張卡 5.1 秒；5 章故事 7.8 秒；按下建立後 12.25 秒大地出現、13.2 秒就能走（起點還在「顯影中」）；原點寫完在 37 秒。整段機器時間 26 秒到能走——現場講話的時間剛好蓋過去。

### 第 2 幕：走路不等 AI（40 秒）
- **做**：往還是一片霧的方向走（一塊地 32 格寬，按住方向鍵走出去）。
- **螢幕**：新的一塊地顯影；地名、道具、居民出現。
- **說**：「我可以一直走，AI 在背景寫這塊地。它寫的不是圖片，也不是程式，而是一小段我們定義的語言，程式驗證過、數值被夾在安全範圍內，才寫進這個世界的歷史。寫過的地方就不再問 AI。」
- 排練量到的數字：一次就寫好的地 6.7 秒（3,522 + 918 token）；需要修正兩輪的地約 23 秒。兩次都一直在走，畫面維持 74–80 FPS。
- **提醒**：demo 用 HD-2D 畫法。16-bit 畫法裡沒有像素圖的道具會畫成灰色方塊加兩個字母（例如 "we"、"pi"）。

### 第 3 幕：朋友的世界連成大陸（70 秒）——CRDT
- **做（A）**：走到家門口，看到「E · 開門」按 E →「向夥伴敞開我的門」→ 念出 6 個字母的門牌 →「關閉」。
- **做（B）**：「← 主頁」→「加入大陸」→ 選自己的存檔 → 在「夥伴的門牌代碼」輸入門牌 →「穿過這扇門」。排練時 578 毫秒後兩邊 HUD 都顯示「大陸 XXXXXX · 已連線 · 1 位夥伴」。
- **做（B）**：在家門口按 E →「前往他們的門」→ B 站到 A 的土地上。
- **螢幕**：B 看到 A 剛才見證的沙漠鐘錶城；A 的畫面上看到 B 在走（按 V 切換兩種畫法）。
- **說**：「B 看到的是 A 寫過的地方，一個字都沒有重新生成——B 的電腦完全沒有呼叫模型。」
- **做（B）**：按 N →「你的留言」寫一句 →「留下留言」。
- **做（A）**：按 N，A 自己的留言面板立刻出現 B 的留言，地圖上也多了留言記號（排練首次驗證，不用重新整理）。
- **說（CRDT，一定要講的那句）**：「這裡沒有伺服器當裁判。每台電腦都有一本自己的冊子，每一頁只能寫一次、而且只有那塊地的主人能寫。兩本冊子碰面，就把對方有、我沒有的頁抄過來。不管誰先誰後、重複收到幾次，最後兩本一模一樣——這就是 CRDT。人在哪裡、面朝哪邊不寫進冊子，只即時廣播，斷線就消失。」
- 已驗證的部分（[milestone-demo-flow](../e2e/milestone-demo-flow/result.md)，另見 [milestone-rev6-land](../e2e/milestone-rev6-land/result.md)）：B 加入之後 B 的 log 裡**沒有任何一次模型呼叫**，A 的三個地方都是抄過來的；A 看到 B 在走，兩種畫法都對；B 的留言寫進 A 的 `notes.jsonl`、作者是 B，也即時出現在 A 的畫面。
- 第 4 幕前的收尾（可省略）：B「← 主頁」→「繼續遊戲」，0.3 秒回到自己的土地、不在 A 那邊、沒有任何模型呼叫。

### 第 4 幕：世界的出處在鏈上（40 秒）
- **做**：打開卡帶清單，指著名稱那一行（例如 `aether-land.unmapped.eth`）。
- **說**：「每個發布的世界版本都有內容雜湊。我們把名字掛在 ENSv2 上，名字指向這個雜湊；改編的世界是它底下的子名稱。改編世界的代幣用 Uniswap 的連續清算拍賣定價，交易時 v4 hook 抽 1% 往上分給每一代的名字持有人。玩家用 passkey 簽名，不需要錢包、不需要 ETH。」（瀏覽器 Touch ID 簽名完成前，不要現場按 Touch ID，見 [track-ens.md](track-ens.md) 的「簽名的限制」。）
- 細節與實際操作：[track-ens.md](track-ens.md)、[track-uniswap.md](track-uniswap.md)；市場操作手冊在 ENSv2 那邊的 `docs/demo/lineage-market.md`。
- **說明底線**：鏈可以整個關掉，前三幕完全不需要鏈。

### 收尾（10 秒）
- **說**：「世界是你自己電腦裡的檔案；AI 只是客人，程式才是規則；鏈可以關掉，世界照樣活著。」

## 評審會問的問題（準備好的回答）

| 問題 | 回答 |
| --- | --- |
| 兩個人同時走進同一塊沒寫過的地怎麼辦？ | 一塊地只有它所在領地的主人能見證，所以同一個 key 永遠只有一個作者；別人送來的已存在的頁會被拒收（`mayWrite`，`src/shared/continentHello.ts`）。 |
| 有人亂送資料？ | 先打招呼：同一個門牌、同一版協定、同一版物理才算通過；沒通過的一方什麼都收不到，送來的也全部丟掉（`src/renderer/net/continentGate.ts`）。每一筆還要過 zod 與 DSL 解析。 |
| AI 寫出壞東西？ | 模型只能寫我們的小語言；解析失敗最多修兩次，之後是錯誤畫面，不會有假內容；所有數字有上下限（`src/dsl/limits.ts`）。 |
| 為什麼用 CRDT 而不是伺服器？ | 世界不能依賴任何人在線，也不能依賴我們的伺服器。只增、每頁一個作者的冊子，合併就是聯集，不需要裁判。 |
| 費用？ | 每次呼叫都記在 `usage.jsonl`，HUD 的用量面板看得到每個世界的累計；金鑰預設讀 `.env`，也可以用本機模型。 |
| 朋友不在線也能進我的世界嗎？ | 現在還不行：大陸是兩邊同時在線時連起來的。離線也能進，是第三段「共同歷史＋世界服務」的目標。 |
